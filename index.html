Proceso de Detección (OpenCV)

Pipeline clásico de visión por computadora para detectar y clasificar monedas.

1. Escala de Grises

Conversión de imagen a un canal usando fórmula de luminosidad: L = 0.299R + 0.587G + 0.114B

2. Blur (Suavizado)

Aplicación de filtro gaussiano 7x7 para reducir ruido y detalles innecesarios.

3. Binarización

Umbral adaptativo + Otsu para separar monedas del fondo.

4. Contornos

Detección de contornos externos y filtrado por circularidad.
